## 🔍 什么是项目号？

项目号是手机厂商在内部研发过程中，为每一款新手机分配的**唯一编码标识**。它本质上是一种内部项目管理工具，用于在整个产品生命周期（从立项、研发、测试到量产）中追踪、管理和协调各项开发工作。

> **举个例子**：OPPO Find X 全网通版的项目号是 `17107`，Find X2 全网通版是 `19065`，Find X3 是 `20061`。这些编号并非随机，而是承载着重要的时间和流水信息。

## 🛠 项目号的核心作用

### 1. 研发阶段的“身份证”
一款新手机从立项到上市通常需要一年以上的研发周期。此时产品还没有正式的商品名和入网型号，项目号便成为其**唯一身份标识**，研发、测试、供应链等各部门通过项目号进行跨部门协作，避免混淆。

### 2. 保密与竞品防护
手机行业竞争激烈，新品信息是核心商业机密。项目号的使用可以**有效防止信息泄露**——即使内部文件外流，竞争对手也无法直接从项目号推断出产品具体信息。

### 3. 固件与软件版本管理
项目号直接关联手机的软件版本和系统固件：
- 在**线刷工具**中，需要选择对应的项目号才能正确刷入固件，选错可能导致设备变砖。
- **OTA 系统更新包**也会校验项目号，只有匹配的设备才能接收和安装对应的更新。

### 4. 生产与供应链管理
同一款手机通常会有多个版本（如不同市场或不同硬件配置），通过不同的项目号进行区分，便于**物料采购、产线排期和质量追溯**。

### 5. 售后与维修支持
售后人员通过项目号可以快速确认设备的**硬件配置、生产批次和适配固件版本**，从而准确判断故障并匹配合适的维修备件。

## 🆚 项目号 vs 入网型号

| 对比维度 | 项目号（Project Number） | 入网型号（Model Number） |
| :--- | :--- | :--- |
| **性质** | 内部管理编码 | 法定合规标识 |
| **生命周期** | 随项目结束而失效 | 贯穿产品整个市场周期 |
| **可见性** | 用户通常不可见（内部使用） | 印在机身、包装盒上，用户可见 |
| **法律效力** | 无（内部管理用） | 工信部入网核准，具备法定效力 |
| **典型用途** | 研发、固件适配、产线管理 | 销售备案、售后识别、监管查验 |

**举例**：OPPO Find X 全网通版的**项目号**是 `17107`（内部研发时使用的项目编号），而它的**入网型号**是 `PAFM00`（印在手机标签上，用于工信部备案）。

## 📝 数据说明

1. **空白项目号**：表格中部分项目号留空，表示暂未获取到公开数据。
2. **多名称合并**：同一行中用 `<br>` 分隔的多个手机名称，表示它们共享相同的入网型号和项目号（通常为同一款手机的不同定制版或限定版）。
3. **数据时效**：本表格数据基于公开信息整理，可能与厂商内部最新数据存在差异，仅供参考。
4. **更新说明**：欢迎提交 Issue 或 Pull Request 来补充缺失或更新错误的数据。
